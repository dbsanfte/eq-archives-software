The archive, connected

Bring EverQuest history into your conversations.

MCP (Model Context Protocol) lets an AI assistant search EQ Archives and read preserved sources. Connect ChatGPT or Claude to research historical websites, mailing lists and newsgroups, with links back to the evidence.

MCP server URL · Streamable HTTP · No authentication

https://search.eqarchives.org/mcp

ChatGPT developer mode

  1. Open Settings → Security and login and enable Developer mode.
  2. Open Plugins and select the plus button to create a custom connection.
  3. Name it EQ Archives, paste the MCP server URL above, and choose No authentication.
  4. Create the connection, review the search and fetch tools, then select EQ Archives from the tools menu in a new chat.

Developer mode depends on your account and workspace settings. For a longer investigation, use the connection as a Deep Research source when that option is available.

ChatGPT connection instructions ↗

Claude

  1. In Claude on the web or desktop, open Customize → Connectors.
  2. Select + → Add custom connector.
  3. Name it EQ Archives and paste the MCP server URL above. Leave the optional OAuth client fields empty.
  4. Select Add, then enable EQ Archives for your conversation under + → Connectors.

For Team or Enterprise, an owner first adds the server in Organization settings → Connectors. Then members can connect to it. Account limits and workspace policies may apply.

Claude connection instructions ↗

Start with a question

Use EQ Archives to research what players reported about camping the Ancient Cyclops for Journeyman’s Boots. Compare several historical accounts, read the original sources, and cite them.

The server offers two read-only tools: search finds sources and fetch retrieves their extracted text and provenance. It cannot change the archive. No EQ Archives account or API key is needed.

Archive capture dates may differ from publication dates. Model-estimated dates and image transcriptions are labelled; check them against the original. The collection and text extraction are incomplete.

What information does the connection send?

Your assistant sends the search queries and document IDs it selects to EQ Archives. The server does not request your full conversation, name, email or assistant account credentials. Search embeddings are generated on the EQ Archives server.

A bounded memory cache reuses query embeddings for five minutes; entries are removed by eviction or a restart. The MCP application does not write query bodies to logs. Infrastructure may record IP addresses, timestamps and errors. Your assistant provider’s own data settings also apply. Use public research topics and avoid private information.
